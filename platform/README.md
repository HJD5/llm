# Локальная платформа Qazaq Loc QA

Откройте http://127.0.0.1:8090 после запуска `start-platform.cmd` в корне проекта. Для остановки используйте `stop-platform.cmd`. Qwen работает отдельно на порту 8088: её можно запустить кнопкой в левой панели или через start-qwen.cmd; остановка модели — stop-qwen.cmd.

## Что можно увидеть

- **Обзор:** структурные проблемы, кандидаты, неопределённые ответы модели, текущий журнал, прогресс по строкам и раскрываемая таблица покрытия всех 11 модулей.
- **Строки перевода:** поиск по ключу и тексту, сравнение RU/KK, английский контекст, выбор строк для точечного запуска.
- **Проверки:** независимое включение 8 кодовых и 3 языковых модулей, выбор всех или отмеченных строк, общий лимит запросов Qwen.
- **История:** завершённые, остановленные и прерванные запуски, повторное открытие отчётов, сохранение настроек.
- **Подробности находки:** объяснение, связанные ключи, ручное подтверждение или отметка ложной тревоги с комментарием. Это проверка находки, не утверждение нового перевода.
- **Ответы Qwen:** цитаты, объяснение, время, использование кэша, исходный ответ и причина перевода в uncertain.
- **Экспорт:** JSON и HTML с текущими отметками проверки. Никаких автоматических изменений ARB.

## Данные и запуск

Набор из basw/handout подключается при старте. Сохранённые отчёты CLI импортируются в историю при совпадении хэшей исходных файлов; они явно обозначены как сохранённые результаты, а не новые проверки.

Кнопка «Загрузить ARB» добавляет отдельный набор: обязательны русский и казахский файлы; английский контекст и глоссарий CSV/JSON необязательны. Максимум 10 МБ файлов через интерфейс и 25000 исходных строк. Колонки глоссария: ru, kk; дополнительно en, note, key и variants (в CSV через |). В текущей версии целевая локаль — kk.

Переводы не меняются. Повторяющиеся ключи сохраняются в диагностике; основной анализ использует последнее значение. Совпадения, длина, варианты терминов и предположения модели не считаются автоматически подтверждёнными ошибками.

Каждый новый запуск работает в отдельном Node worker, поэтому интерфейс доступен во время генерации. Одновременно выполняется один запуск. Остановка прекращает worker и сохраняет уже полученный отчёт. При аварийной остановке сервер помечает ранее выполнявшийся запуск как прерванный; последнее несохранённое обновление может быть потеряно. Запуск автоматически не возобновляется. Кэш позволяет повторить завершённые запросы без генерации.

По умолчанию выбраны кодовые проверки; Qwen включается отдельно. Бюджет относится ко всему запуску, не к каждой строке. Задачи сверх бюджета помечаются как отложенные. Кэшированные ответы бюджет не расходуют. Глоссарий без файла помечается как отсутствующий. Даже если прогресс достиг 100%, отдельные модули могут быть пропущены или отложены — смотрите покрытие.

## Хранение

Загруженные наборы, история, комментарии и журналы находятся в platform/private-data. Кэш модели остаётся в locqa/private-results/cache. Обе папки и basw исключены из Git. Нет внешних шрифтов, аналитики или API: браузер общается с локальным сервером, сервер — с локальной Qwen. Сервер привязан к 127.0.0.1 и не доступен другим устройствам по сети. Проверяются Host, Origin и токен изменяющих запросов.

Это локальная однопользовательская платформа. Авторизации и совместной работы нет. Имя проверяющего в отметках — local_user; отметка означает фактическое нажатие пользователем, а не верификацию квалификации носителя языка.

## Разработка и проверки

Node.js 24; используются уже установленные зависимости locqa. В новом окружении сначала `npm.cmd ci --ignore-scripts --prefix locqa`, затем `node platform/server.mjs`.

```powershell
node --test platform/server.test.mjs
npm.cmd test --prefix locqa
```

Интеграционные проверки используют отдельные временные данные: загрузка, некорректные ARB, защита API, выполнение реального worker, отмена, запрет параллельного запуска, отметки человека, экранирование HTML и сохранение после перезапуска. Исходные данные конкурса тестами не меняются.

Проверено получение HTML/JS/CSS через HTTP и подключение к Qwen. Визуальная проверка через автоматизированный браузер не выполнена: служба доступа к браузеру была недоступна. Платформа не опубликована в интернете.
