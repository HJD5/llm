# Повторная проверка локализации

В `src/neighbor-context.mjs` добавлен контекст двух соседних ключей в том же разделе. В CLI он включается `--context-neighbors`; в повторной проверке кейса используется автоматически. Длинные соседи сокращаются только как дополнительный контекст; сама проверяемая строка не обрезается.

`src/arb-edits.mjs` применяет точечные изменения через AST JSON. Сохраняет все вхождения `@@comment`, дубли строковых ключей, метаданные и несвязанные значения. Совпадающие дубли исправляются во всех вхождениях. Различающиеся дубли требуют явного ожидаемого значения, иначе изменение блокируется. Машинная проверка никогда не ставит `reviewed_by_human=true`.

Глоссарий поддерживает явно заданные `source_variants` и `variants`, а также `match_mode=phrase` для границ слов внутри предложений. Это не общий морфологический анализатор: неизвестное склонение остаётся кандидатом. Совпадение подстроки внутри другого слова не считается термином.

Термины со статусом `proposed`, сверенные при разборе по RU/EN и контексту, помечаются `verification=ru_en_context_crosscheck`. Их применение как правил требует явной настройки:

```json
{"include_machine_validated_glossary": true}
```

По умолчанию эти записи не становятся утверждёнными правилами. Human Review сохраняет отдельный смысл; машинная сверка не заменяет носителя.

`full-language-audit.mjs` — экспериментальная пакетная проверка трёх языковых категорий существующей Qwen. Записывает отдельные ответы, хеши запросов и прогресс, не теряет результат при перезапуске. Слишком большой контекст разбивается, а не обрезается. Встроенный контроль на известных чужоязычных строках останавливает массовую обработку, если модель объявляет их корректными. Такой остановленный прогон нельзя выдавать за проверку всего файла.

На данном запуске пакетный режим не прошёл этот контроль. Отдельные вызовы исходных детекторов сработали лучше, но не покрыли весь файл. Фактическое покрытие указано в отчёте. Чтобы продолжить полную языковую проверку на GPU, переносится тот же код и модель Qwen3-8B; менять местами source/target или объявлять кеш/отсутствие ответа успешной проверкой нельзя.

`src/audit-decisions.mjs` и `src/audit-glossary.mjs` — открытый журнал конкретных решений для предоставленного кейса, а не универсальные подстановки в движке. Неоднозначные случаи не включены в исправления. Все изменения фиксируются с RU, EN, прежним KK и причиной.
